# Contributing

- Target Minecraft 26.3, Fabric API 0.162.0+26.3, and Java 25. This is a fresh world release.
- Keep authored structures in `builds/` and regenerate NBT through the schematic pipeline. Do not overwrite player worlds.
- Preserve asset licenses and source references in `credits.md`.
- Verify world generation, encounters, and navigation in a fresh world before changing a release jar.
