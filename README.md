# Second Chance

A Minecraft 26.3 Fabric adventure about a friend group whose stories reshape the world. Explore distinct regions, solve places through their surroundings, face bosses, and bring discoveries home to the shared town.

Install the 2.0 Second Chance and [Gems of Fate](https://github.com/mahmoudelfeelig/Gems) jars with Fabric Loader 0.19.5+, Fabric API 0.162.0+26.3, TerraBlender Fabric 26.3.0.0.7+, and Java 25. Start a fresh world.

Clone with submodules (`git clone --recurse-submodules`), then run `./gradlew build` (`gradlew.bat build` on Windows). The campaign jar is in `build-win/libs/` on Windows or `build-wsl/libs/` on Linux. See [campaign notes](docs/adventure/CAMPAIGN.md), [editable builds](builds/README.md), and [asset credits](credits.md). See the [server guide](server-ops.md) for install and admin commands.
